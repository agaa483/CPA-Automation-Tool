# Icons

Chrome extensions require icons at 16×16, 48×48, and 128×128 px (PNG).

Replace this file with three real icons:
- `icon-16.png`
- `icon-48.png`
- `icon-128.png`

For rapid dev, you can generate quick placeholder icons at https://favicon.io/ or
similar. Chrome will show a broken image icon in the toolbar if PNGs are missing
but the extension will still function.
